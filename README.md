# Gara - Tienda de Sahumerios y Accesorios

Este proyecto es una propuesta web para **GARA**, un emprendimiento enfocado en la comercialización de sahumerios artesanales, elementos de defumación y accesorios.

## Propósito de la página

Brindar a los clientes un catálogo claro y atractivo de productos, testimonios de satisfacción y un formulario interactivo para consultas comerciales.

## Tecnologías aplicadas

- **HTML5 Semántico**: `header`, `nav`, `main`, `section`, `footer`.
- **CSS3**: Layouts adaptativos con Flexbox, CSS Grid y Media Queries.
- **Google Fonts**: Tipografías *Montserrat* y *Playfair Display*.
- **Formspree**: Manejo funcional para el envío del formulario de contacto.
